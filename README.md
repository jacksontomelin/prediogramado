# 🏔️ Aire Gramado Zagonel — Voucher App

App de controle de acesso para visitante do condomínio **Aire Gramado Zagonel**, Gramado/RS.

## ✨ Funcionalidades

- **30 portas/acessos** em layout de bolinhas (grid responsivo)
- Categorias por cor: escadas, elevadores, lazer, portaria, garagem, visitante, morador
- **Popup de confirmação** interativo com ripple + vibração háptica
- **Popup de sucesso** com barra de progresso e auto-fechamento
- Indicador de validade em tempo real
- Tema visual: Gramado/RS — floresta de pinheiros, neve, paleta verde escuro e dourado
- PWA-ready, 100% client-side

## 🛠️ Tecnologias

- HTML5 + CSS3 + Vanilla JS (zero dependências)
- Google Fonts (Playfair Display + Inter)
- Animações CSS puras
