MÉTODO 1 Console (mais rápido)

1. Abra a página do voucher original no navegador
2. Abra o Console (menu ⋮ → Mais ferramentas → Ferramentas do desenvolvedor → Console). No iPhone use Safari no Mac conectado, ou o app Inspect.
3. Cole o código abaixo no Console e aperte Enter:
// Intercepta TODA requisição de rede (function(){ const _fetch = window.fetch; window.fetch = function(...a){ console.log('%c[FETCH]','color:#4cde8a', a[0], a[1]||''); return _fetch.apply(this,a); }; const _open = XMLHttpRequest.prototype.open; XMLHttpRequest.prototype.open = function(m,u){ console.log('%c[XHR]','color:#e6c96d', m, u); this.addEventListener('load',function(){ console.log('%c[XHR RESP]','color:#4cde8a', u, this.status, this.responseText.slice(0,200)); }); return _open.apply(this,arguments); }; console.log('%c✅ Interceptor ativo! Agora clique ABRIR numa porta.','color:#c8a84b;font-size:14px'); })();
4. Clique numa porta → Abrir. Vai aparecer [FETCH] ou [XHR] com a URL.
5. Copie tudo que apareceu e cole aqui no chat.
